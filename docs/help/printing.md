title: Print modes, paper, and margins
keywords: print preview paper margins PDF landscape count sheet

Choose Configure Layout to select a print layout, paper size, orientation, and margins. Generate a preview and inspect page breaks before printing. The print view uses a light theme.

For a simple portrait sheet, choose Count Sheet → FOR SPR. Upload SKU, BARCODE, and DESCRIPTION columns, then print or export PDF. SPR includes one blank count column, needs no CCD or locator data, preserves uploaded row order, and uses Letter portrait with 14 rows per page.
